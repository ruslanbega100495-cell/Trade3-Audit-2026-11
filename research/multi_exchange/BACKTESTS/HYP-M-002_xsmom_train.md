## Метод

- **Универсум:** 25 USDT-перпов Bybit (BTC ETH BNB SOL XRP DOGE ADA AVAX DOT LINK LTC BCH NEAR UNI TRX XLM XMR AAVE CRV OP APT INJ HBAR STX ZEC), H4, 2022-11-01 → 2025-04-01.
- **Синхронизация:** inner join close-матрицы — только бары, присутствующие у всех 25 символов (5272 бара). Look-ahead-safe.
- **Сигнал:** momentum = close[t]/close[t−L] − 1, ранжирование по кросс-секции на закрытии бара t.
- **Позиции:** доллар-нейтрально, long top-k и short bottom-k, равные веса, gross = 1 (каждая нога 0.5). Позиции с бара t+1, удержание H баров, ребаланс каждые H баров.
- **Издержки:** taker 0.00055 + slippage 0.00050 на сторону, полный оборот (закрытие + открытие) каждую ребалансировку = 0.0021 на период при gross=1.
- **Funding:** фактические исторические ставки Bybit, as-of join (только прошлые записи). События 00:00/08:00/16:00 UTC на удерживаемые позиции. Конвенция **проверена по данным**: средний funding_rate > 0 (~8e-5/8h, 76–90% положительных записей) → long платит, short получает.
- **Annualization Sharpe:** √(6·365/H). **CI mean:** circular block bootstrap (блок ≈ √n периодов, 10000 ресэмплов).
- **DSR:** Deflated Sharpe Ratio (Lopez de Prado, AFML ch.8), N = 12 испытаний, порог 0.95 — см. docs/VALIDATION_PROTOCOL.md (multiple testing).

## Вердикт

**REJECTED (TRAIN).** Ни одна из 12 заранее зафиксированных комбинаций не проходит success criteria:
1. Все H=4 (частая ребалансировка) — устойчиво отрицательны: издержки 0.21%/период съедают momentum-преимущество полностью.
2. Лучшие H=12/k=3 варианты (L=24, L=96) — слабоположительны (PF 1.07–1.09), но CI включает 0, DSR ≤ 0.15, при 2× издержках отрицательны.
3. Funding-вклад положительный, но мизерный (+2–4% суммарно) — не спасает.
4. Знаки по полугодиям нестабильны; последний субпериод (2025-01→2025-04) отрицателен у всех.

Кросс-секционный momentum на 4-дневных горизонтах на этой кросс-секции не подтвердился.

## Ограничения и bias

- **TRAIN-only / exploratory:** окно 2022-11→2025-04 — единственный multi-symbol период; независимой валидации нет (OOS 2025-10→2026-10 consumed, VALIDATION 2025-04→2025-10 зарезервирован HYP-H16 по D-001). Confirmatory возможен только на post-2026-10 данных.
- **Survivorship bias:** 25 символов = текущий ликвидный список на 2026-11; делистed/неликвидные символы 2022–2025 исключены → результат может быть завышен, т.е. истинное качество сигнала ещё хуже.
- Концентрация PnL: топ-1 символ даёт 11–17% |ΣPnL| (STX/SOL/HBAR/XLM/TRX) — зависимость от одиночных альтов.
- Результат является валидным отрицательным результатом и остаётся в реестре (Negative Results Policy).
