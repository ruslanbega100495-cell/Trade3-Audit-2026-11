## S-01. Cross-venue OI dispersion: OI-Δ лидера → forward-движение

**Гипотеза.** Изменение OI (не уровень) на самой крупной бирже Bybit предсказывает краткосрочное движение/разворот на остальных. Механизм: OI-Δ — прокси принудительного/нового позиционирования; перегретый рост OI на падающей цене = шорт-краудинг (хрупкость), рост OI на растущей = лонг-краудинг. Cross-venue вариант: разнонаправленные OI-Δ между Bybit и OKX = расхождение позиционирования → последующая конвергенция потоков. ОТЛИЧИЕ от отвергнутых «OI-экстремумов» (G/H-001): сигнал — **первая разность OI нормированная на оборот**, на горизонте 1–24ч, а не экстремум уровня как реверсал-триггер.

**Данные.** Есть: Bybit BTC/ETH OI (H4 2024-01→2026-09, история API полная — можно качать 1h). Нет: OI-история OKX >6 мес (Rubik), KuCoin/HTX/WEEX/BingX — нет. Cross-venue компонент — только prospective (WS: Bybit OI-поллинг 5мин + OKX OI в тикерах уже пишутся).

**Тест без look-ahead (exploratory).** Регистрация ДО прогона. TRAIN: Bybit-only, BTC 1h OI 2024-01→2025-04: форвардные доходности t+1/4/24h vs ΔOI_t, ΔOI_t/turnover_t, ΔOI_t × sign(ret_t). Режимная стратификация (RV-квантили). Критерии: |t| ≥ 3, эффект > 2× round-trip (10 bps) на горизонте ≥ 4ч, устойчивость по полугодиям. Для кросс-веню: сопоставление потоков OI Bybit↔OKX из WS после ≥2 недель записи (точная синхронизация recv_ts, без интерполяции).

**Издержки.** Taker 10 bps round-trip; OI-сигнал на горизонте 4ч+ совместим, на 1ч — под вопросом. Не требует одновременного исполнения на двух веню (Bybit-only версия).

**Оценка.** Edge 2–3 / Частота 3 / Ёмкость 3 / Конкуренция 2 / Сложность 2. **Survivor: 20–25% standalone, ~40% как режимный фильтр.** Литература поддерживает: Tran et al. 2026 (2.65M 8h-наблюдений Binance): OI-Δ + funding + RV предсказывают ≥5% крахи 8h, OOS AUROC 0.76, OI-Δ BTC — сильнейший кросс-ассетный предиктор. Cross-venue OI-дисперсия как сигнал — академически пустая ниша (проверено: работ нет) → novelty есть, но и гарантий нет.

## S-02. Funding autoregression / предсказуемость следующего funding

**Гипотеза (в честной форме).** Следующий funding почти механически предсказуем из текущего premium index: Bybit публикует формулу `F = clamp[AvgPremium + clamp(I−P, ±0.05%), cap, floor]`, premium — линейно взвешенный TWAP (последние минуты окна доминируют). За минуты до метки current basis ≈ next funding — это публичный прогноз биржи, edge ≈ 0 для standalone. Реальная ценность: (а) **cost-model для M-003** — предсказанный expected funding вместо последнего реализованного при выставлении carry-пар; (б) Tobit-модель цензурирования (внешний кап = min((IMR−MMR)×0.75, MMR), в волатильность регулируемый 0.5–1.0×) для сигналов «у упора»; (в) funding-dispersion **surprise** (реализованный − предсказанный) как событие — см. S-03. Торговать саму автокорреляцию funding нельзя: это артефакт формулы, известный всем.

**Данные.** Есть: полная funding-история Bybit (BTC/ETH/25 альтов), spot+perp klines. Историческая внутриоконная динамика premium — НЕТ (нужен тиковый premium или хотя бы минутный basis; H1 klines с 2024-04 дают грубую картину только).

**Тест.** Не регистрировать как торговую гипотезу. Оформить как исследование: качество прокси «basis → next funding» на H1 (R², ошибка), калибровка Tobit на альтах 2022-11→2025-04 (где funding-периоды и уровни шире). Выход — параметры в cost-модель M-003 и признак surprise для S-03.

**Оценка.** Edge 0–1 standalone / — / — / Конкуренция 5 (полностью арбитражено формулой) / Сложность 1. **Survivor standalone: <5%.** Рекомендация: делать как компонент, не как стратегию. Связано с литературой: PERP3 (Cao et al. 2026) — basis/funding как priced state variable; funding-surprise dispersion предсказывает BTC downside (Pindza 2026) — это мост к S-03.

## S-03. Insurance fund flows + композитный venue-stress score

**Гипотеза.** Неожиданное истощение insurance fund биржи (ΔIF/IF за окно) — режимный маркер стресса: коррелирует с кластеризацией ликвидаций, ростом RV, отказом MR-краёв. Не standalone-сигнал, а **мастер-фильтр**: stress↑ → размеры позиций ↓, MR/возвратные стратегии off, carry-размер режется, тейк-профиты ужимаются. Граница с M-004: M-004 торгует послекаскадное восстановление по событиям; S-03 — непрерывный скаляр риска, детектирует накопление до каскада.

**Данные.** `/v5/market/insurance` отдаёт только snapshot (проверено живым запросом 2026-11-09) → истории нет. Нужен поллинг 1 раз/5–15 мин в WS-регистратор (1 GET, вне rate limits). Академических работ по insurance fund как индикатору НЕ найдено — practitioner-фича (Kaiko/CryptoQuant трекают; канонический кейс — стрижка insurance Binance ETH в мае 2021). Статус: novelty ✔, валидации ✘.

**Тест без look-ahead.** Опцион А (быстрый, без записи): восстановить IF-историю по архивам CryptoQuant/качеству данных — вероятно платно; пропустить. Опцион Б (правильный): добавить поллер IF в регистратор → ≥4–6 недель → описательная корреляция ΔIF vs forward RV, частота совпадений с allLiquidation-каскадами (уже пишутся), регрессия P(каскад | ΔIF, funding z, OI-Δ velocity). Композит: stress score = w1·z(ΔIF) + w2·z(|funding surprise|) + w3·z(ΔOI/turnover) + w4·z(liquidation intensity); веса фиксируются ДО анализа, либо равные.

**Издержки.** Ноль (данные публичные, поллинг дешёвый). Ценность реализуется через снижение просадки других стратегий, не через PnL напрямую.

**Оценка.** Edge (как мультипликатор) 2–3 / Частота n/a (фильтр) / Ёмкость n/a / Конкуренция 1 / Сложность 1–2. **Survivor: 45–55% как фильтр** (риск — фича окажется редкой/шумной: крупные стрижки IF случаются раз в годы; тогда ценность только хвостовая).

## S-04. Basis oscillation вокруг funding-меток

**Гипотеза.** Basis (perp−spot) mean-reverts к нулю к концу funding-окна (арбитражёры гасят премию перед меткой) и отскакивает после неё. Сезонная (внутрисуточная, 3-цикловая) компонента basis.

**Данные.** Есть: Bybit spot+perp klines (H4/H1 с 2024-04), funding-история. Нет: минутный basis 2024-2026 (H1 — самое мелкое зерно; внутриоконная структура на H1 видна грубо).

**Честная оценка границ.** (1) BTC: типичная амплитуда basis — единицы bps против 10 bps round-trip → структурно мертво, тестировать смысла нет (M-001 и M-005 уже показали порядок величин расхождений). (2) Альты 2022-11→2025-04: funding-амплитуды 10–75 bps (у части альтов почасовой funding — M-002 audit), basis-колебания кратно больше издержек → **единственная жизнеспособная ветвь**. (3) Риск дублирования: направление «standalone сезонности» и «funding экстремумы-реверсалы» в реестре отвергнуты — поэтому регистрировать ТОЛЬКО как exploratory-исследование с жёстким kill-критерием, не как торговую гипотезу; полезный побочный выход — параметры time-of-funding фильтра (уже планируемого как компонент M-003).

**Тест без look-ahead.** По часам до/после метки 00/08/16 UTC: basis(t) − basis(mark) на 25 альтах; HAC-оценка сезонного профиля; торговый прогон только если сезонная амплитуда > 4× round-trip на ≥30% альтов, устойчиво по полугодиям. Исполнение — maker-лимитки внутри спреда (0.02% комиссия) вместо taker.

**Оценка.** Edge 1–2 / Частота 3 (3 цикла/сутки) / Ёмкость 1–2 / Конкуренция 4 / Сложность 2. **Survivor: <10%** (главная угроза — арбитражёры гасят именно эту сезонность; эффект, вероятно, виден уже в марке).

## S-05. Cross-venue lead-lag (predictive) + pairs на альт-перпах с пороговым входом

**Гипотеза.** Ret лидера (Bybit/OKX) в баре t предсказывает ret отстающих веню в баре t+1 (H1/H4). Отличие от M-001 принципиально: M-001 мерил **contemporaneous** |дислокацию| закрытий; здесь — временная регрессия с лагом, rolling information-share (Hasbrouck/Gonzalo-Granger), торговля t+1. Pairs-вариант: cointegration-остаток цен двух веню + threshold entry (в M-001 не тестировался как торговая стратегия, только распределение дислокаций).

**Честная оценка.** BTC H1: почти наверняка мёртв — если бы лидер предсказывал laggard на часовом горизонте с краем > 10 bps, это было бы видно как персистентные дислокации (M-001: 1 событие за 2.5 года). Реалистичное ожидание: R² < 1%, net отрицателен. **Но сама lead-lag-регрессия формально не прогонялась** — тест стоит день, регистрируется как exploratory с предзаявленным kill-критерием (эффект < 2× cost ⇒ закрыть, параметры не подгонять). Живая ветвь — **альт-перпы**: лаги структурно больше, funding у веню различается (ветвь, не закрытая M-005: BTC-only), персистентность остатков выше. Пороговый вход на остатке + maker-исполнение: порог ≥ 25–50 bps на неликвидных альт-перпах, позиции держать до конвергенции, funding-недоучёт моделировать.

**Данные.** BTC H1 6 веню 2024-04→2026-11 — есть. Альт-перпы мульти-веню — надо качать (klines API у всех есть; KuCoin интрадей с 2024-08, HTX H1 только ~3 мес, BingX с 2024-04, WEEX с ~2020).

**Издержки.** Taker 10 bps / maker 2–4 bps; риск одноногого исполнения на двух веню — главный operational риск; WEEX — counterparty-лимит обязателен.

**Оценка.** Edge 1 (BTC) / 2–3 (альты) / Частота 2 / Ёмкость 1–2 / Конкуренция 3 / Сложность 3. **Survivor: BTC <5%; альт-версия 15%.**

## S-06. Vol-of-vol / jump forecasting → sizing-оверлей

**Гипотеза.** RV кластеризуется на двух уровнях (vol-of-vol); jump-компонента (bipower variation vs realized variance) предсказуема краткосрочно. Не сигнал направления — **мультипликатор плеча**: predicted jump-risk↑ → size↓, stop-дистанции↑. Реализация «режимной обвязки» (#9 в STRATEGY_IDEAS) конкретным численным протоколом.

**Данные.** Есть: H1 klines 6 веню (2.5 года), Bybit H4 2022-11→2025-04, альты. Больше ничего не нужно — тестируемо сегодня.

**Тест без look-aheads.** Rolling-окно: RV_t+1 (proxy — сумма кв. доходностей следующего бара) ~ AR на RV, vol-of-vol, jump-тест Barndorff-Nielsen–Shephard на прошлых барах. Метрики: калибровка (реализованный RV vs предсказанный, покрытие интервалов), **экономическая**: портфель H16-стиля (или синтетический momentum) с/без оверлея — снижение MaxDD и left-tail при той же средней доходности. Регистрация как исследование инфраструктуры, не как гипотеза alpha.

**Оценка.** Edge 1–2 (только через DD-редукцию) / Частота n/a / Ёмкость n/a / Конкуренция 1 / Сложность 2. **Survivor: 60–70% как инфраструктура** (GARCH/jump-кластеризация — один из самых воспроизводимых эффектов в количественных финансах; вопрос только в пользе для ёмкости $1–10k — ограниченной).

## S-07. Стаканная микроструктура из WS orderbook.50 (descriptive для Track A)

**Гипотеза-программа.** На накопленной записи Bybit BTC orderbook.50 + publicTrade: (1) распределение времени жизни спреда; (2) частота и величина adverse selection в N мс/сек после касания best-bid (realized spread decomposition); (3) интенсивность обновлений стакана как функция RV-режима; (4) доля «толстых» спредов > X bps по режимам — где Track A-захват спреда вообще теоретически покрывает комиссию+adverse selection.

**Данные.** Уже пишется (92 МБ/сутки). Неделя записи достаточна для (1),(3),(4); для (2) нужны ≥2–4 недели (adverse selection — редкое событие на BTC, который ликвиден — **честно: на BTC эффекты будут слабее, чем на неликвидных альтах, для которых стакан не пишется; это ограничение выводов**).

**Статус.** Не торговая гипотеза — research agenda. Выход: параметры Track A (min edge, inventory limits, cancel-latency бюджет, расписание активности вокруг funding-меток, когда adverse selection выше). Сэмплирование обязательно (полный день orderbook.50 — сотни МБ).

**Оценка.** Edge n/a / — / — / Конкуренция n/a / Сложность 2 (обработка). **Survivor: 80%+ как исследование** (риск только в объёме обработки).

## S-08. Venue turnover-share rotation (ритейл-фроз contrarian-фильтр) — собственная идея

**Гипотеза.** Доли оборота веню share_i = turnover_i / Σturnover (по 6 биржам) мигрируют: всплеск доли tier-2 (WEEX/BingX/KuCoin) относительно лидеров = ритейл-фаза/фрот → краткосрочный contrarian-риск (перегрев) → снижать risk-on экспозицию; миграция обратно к лидерам = институциональная фаза → risk-on. Механизм: tier-2 трафик проксирует розничную толпу (продвижение, бонусы), литературно подтверждённое направление «informed flow концентрируется в агрессивных ордерах в волатильность» (Ghysels & Nguyen 2018). Академических работ именно по turnover-share как сигналу НЕТ — novelty ✔.

**Данные.** Уже скачано: H1 klines 6 веню 2024-04→2026-11, в каждой свече есть **turnover**. Больше ничего не нужно. Самая дешёвая идея отчёта.

**Тест без look-ahead.** Регистрация ДО прогона. Метрики: Δshare_tier2(t) (4h/24h окна), стандартизированные по rolling 60-дневной истории (учесть структурный рост долей tier-2 от маркетинга — нормировка обязательна). Регрессия forward ret BTC (t+1..t+24) на Δshare с контролем RV и собственного ret; walk-forward по полугодиям. Формы: (а) contrarian-фильтр для momentum/возвратных входов; (б) stress-признак в S-03. Kill-критерий: |t| < 3 или знак нестабилен по полугодиям ⇒ закрыть.

**Издержки.** Ноль — чистый фильтр, торгует существующие стратегии. Как standalone-направленный сигнал не рассматривать (edge < издержек почти гарантированно).

**Оценка.** Edge 1–2 (как фильтр) / Частота n/a / Ёмкость n/a / Конкуренция 1 / Сложность 1. **Survivor: 25–35% как фильтр, <5% standalone.**

## ТОП-3 и порядок первых тестов

1. **S-01 (OI-Δ lead)** — лучшее сочетание: данные уже есть (Bybit OI-история + klines), литературная поддержка сильнейшая (OI-Δ — верифицированный предиктор крахов, Tran et al. 2026), кросс-веню-ниша академически пуста (novelty), конкуренция низкая. Первый тест: exploratory-регистрация + прогон Bybit-only BTC 1h OI ΔOI/turnover → forward returns на TRAIN 2024-01→2025-04, предзаявленные критерии, один день работы. Параллельно OI-поллинг уже копит кросс-веню данные для confirmatory.
2. **S-03 (insurance/stress score)** — дешевле некуда: 1 эндпоинт, 1 поллер в регистраторе, нулевая конкуренция, ценность через выживаемость всего портфеля (самый надёжный тип апгрейда по литературе 2024–2026). Первый тест: добавить IF-поллинг в ws_recorder сегодня; confirmatory через 4–6 недель. Побочный быстрый выход: funding-surprise (S-02) как третий компонент score — без новых данных.
3. **S-08 (turnover-share rotation)** — нулевой cost входа: всё уже скачано, включая turnover. Один exploratory-прогон за несколько часов; если |t|≥3 и стабильность по полугодиям — мгновенно становится фильтром для всех будущих стратегий; если нет — закрыто с доказательством. Честная оговорка: эвристика practitioner-уровня, валидирующей литературы нет.

**Явно не рекомендую тратить цикл сейчас:** S-04 и S-05-BTC (структурно закрыты порядком величин из M-001/M-005; только альт-ветви, и те — после дешёвого exploratory с kill-критериями); S-02 как standalone (артефакт формулы, арбитражено всеми; делать только cost-модель для M-003).

## Ограничения

- Литература 2026 года по funding/OI — в основном preprints (SSRN/arXiv), не peer-reviewed; факты микроструктуры (осцилляция basis, миграция объёма) — desk lore, не академия.
- Все исторические тесты выше — exploratory по PERIOD_MAP (чистых периодов нет); survivor-оценки учитывают необходимость prospective-подтверждения.
- Биржевые метрики tier-2 (WEEX/BingX) — по одному источнику (их API), кросс-проверка невозможна; структурный рост их долей может маскировать сигнал S-08.
