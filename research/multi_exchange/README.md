# MULTI-EXCHANGE RESEARCH STORAGE — Trade3

Хранилище результатов автономного мультибиржевого исследования (шесть бирж: Bybit, WEEX, BingX, KuCoin, OKX, HTX; Binance исключён).

## Правила работы

1. **Неизменяемость истории.** Старые результаты не удаляются и не переписываются. Новая версия гипотезы — новый ID/версия со ссылкой на старую.
2. **Регистрация до результатов.** Гипотеза регистрируется (YAML) ДО просмотра результатов её тестирования. Иначе статус только `exploratory`.
3. **CONSUMED-периоды** (см. `PERIOD_MAP.md`) не использовать как новые holdout. Новый независимый HOLDOUT — только из будущих данных post-2026-10-01.
4. **HYP-L-001 на паузе** — не возобновлять как эксперимент. Пересекающиеся темы изучать под новыми ID.
5. **TRADING_DISABLED=True** — никаких ордеров (реальных/demo), никаких API-ключей в отчётах.
6. **Отрицательные результаты обязательны** — в `REJECTED/` и в YAML гипотезы.
7. **Датасеты**: метаданные + sha256 в `DATASETS/DATASETS.md`; raw и normalized разделять; повторно не скачивать.
8. **Пороги edge** — только из `docs/VALIDATION_PROTOCOL.md` (≥200 сделок TRAIN, 95% CI expectancy > 0, 2× издержки, DSR при >10 комбинаций). Свои пороги не выдумывать.

## Начало новой сессии

Читать в порядке: `PROGRESS.md` → `MASTER_REPORT.md` → `PERIOD_MAP.md` → последние отчёты в `AGENTS/` → реестр `research/registry/HYP-*.yaml`. Продолжать с последней подтверждённой точки, не повторять тесты без обоснования новизны.
