# D-001 — Распределение периода VALIDATION 2025-04-01→2025-10-01

Дата: 2026-11-08. Статус: ПРИНЯТО.

## Контекст
Единственный крупный непросмотренный исторический период Bybit H4 (1098 баров) конкурировал между:
- HYP-H16 (TSMOM): TRAIN завершён, параметры заморожены (лучший вариант: N=12, vol-scaled, target_vol 0.20; все 3 варианта положительны post-cost). Валидация — следующий протокольный шаг, блокеров методологии нет.
- HYP-A-001 (TREND_UP/LONG): 2 открытых блокера (WF-B методология не задокументирована; конфликт DECISION.md «WEAK — DO NOT ADVANCE» vs CANDIDATE_GATE «PRIMARY»).

## Решение
Период выделяется **HYP-H16 VALIDATION** с замороженными параметрами.

## Обоснование
1. H16 — единственная гипотеза, прошедшая TRAIN без открытых методологических блокеров; протокол требует валидации до любого расширения.
2. A-001 нельзя валидировать, пока не закрыты блокеры — иначе результат невалиден методологически.
3. Один период — одна гипотеза: это исключает множественный просмотр (селективное использование).
4. H16 не считается доказанной: TRAIN-результат (Sharpe 1.577, n=225) — только основание для валидации.

## Последствия
- После просмотра результата период 2025-04→2025-10 становится USED (см. PERIOD_MAP.md).
- Если H16 валидация пройдёт — следующий шаг walk-forward по TRAIN+VALIDATION, затем только prospective holdout (post-2026-10-01).
- Если провалится — гипотеза фиксируется как REJECTED (VALIDATION_FAIL), без подгонки параметров.
